**Description**

During this project i recoded some functions from the libc, for instnace *atoi*, *strlen*, etc. 
But also some additonal functions that are either not in the libc, or that are part of it but in a different form. Finally we 
implemented functions using a structure in order to manipulate linked lists.

**Instructions**

In order to compile all the files, I made a *makefile*
make        # builds libft.a
make clean  # removes object files
make fclean # removes object files and libft.a
make re     # fclean + all
Compiled with **cc -Wall -Wextra -Werror
